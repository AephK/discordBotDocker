Simple Discord bot written in Python using [discord.py](https://github.com/Rapptz/discord.py) and [YT-DLP](https://github.com/yt-dlp/yt-dlp)

---

## Features:
### ?v [url] : passes a video URL to the bot, which will then download and convert to a Discord compliant .mp4 and send to the chat with a caption stating which user sent the video and an embedded link to the video's source. For example: ?v https://www.youtube.com/watch?v=dQw4w9WgXcQ
